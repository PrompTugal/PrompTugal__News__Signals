## The focus (from conductor.b@'s brief to signals.b@, at Dinis's word)
What organisations are saying now about the places and topics PrompTugal.news covers (AI, startups, security, Web Summit, each place), built from data.promptugal.news's API (`/api/v1/social/`, `/discovery/`, `/events/`, `/sources/`). This repository runs no collectors and makes no model calls; data.b@PrompTugal.dinis owns them.

- Organisations' official public accounts only, never a private person.
- Posts shown by link or the platform's own embed, never copied text or media.
- Each post with its account, platform, time, licence "the platform's terms" and the evidence it supports. Perplexity finds credited.
- Pages: home (latest signals), one per place, one per topic, one per organisation account, /how/, /security/, the take-down disclaimer; masthead and sites rail as the other sites.
